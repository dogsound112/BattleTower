# COBBLEVERSE Battle Tower Website

GitHub Pages에 바로 올릴 수 있는 배틀타워 **1~100층 트레이너 파티 정보 사이트**입니다.

## 전투 규칙
- RCT 기반 6 vs 6 싱글
- 전 포켓몬 Lv.100
- 전 포켓몬 IV 6V
- **1~49층: EV 미투자**
- **50~100층: 역할별 실전 EV 적용**
- 50층 이후부터 전설 / 준전설 / 환상 / 초전설 비중이 크게 증가
- 체크포인트 시스템 없음

## 사이트 기능
- 1~100층 전체 파티 표시
- 10층 단위 구간 탭
- 포켓몬 / 기술 / 특성 / 도구 검색
- 각 포켓몬의 특성 / 도구 / 기술 4개 / IV / EV 표시
- 50층 이상은 `실전 EV 적용` 배지 표시

## 50층 이후 난이도
- 50~59F: 실전 EV + 준전설/환상/전설 다수
- 60~69F: 초전설 본격 등장
- 70~79F: 초전설 중심
- 80~89F: 전설급 5~6마리 편성
- 90~99F: 사실상 전원 최상위 전설
- 100F: 배틀타워 최종 가디언
