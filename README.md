# COBBLEVERSE Battle Tower Website

배틀타워 **1~100층 트레이너 파티 정보** GitHub Pages 파일입니다.

## 후반 규칙
- 1~49F: Lv.100 / IV 6V / EV 미투자
- 50~100F: Lv.100 / IV 6V / 역할별 실전 EV
- 51~100F: **메가진화 / 테라스탈 / 다이맥스·거다이맥스 사용 가능**
- 일부 최종 구간은 울트라버스트 등 특수 폼도 사용
- 체크포인트 없음
